# Android Homework 2 - Registration Form

ეს არის ანდროიდის დავალება #2: სარეგისტრაციო ფორმის იმპლემენტაცია Jetpack Compose-ის გამოყენებით.

## ფუნქციონალი
- **სახელი, გვარი და იმეილი:** გამოყენებულია `OutlinedTextField`.
- **დაბადების თარიღი:** გამოყენებულია Material3 `DatePicker` მოსახერხებელი წლების არჩევანით.
- **პლატფორმის არჩევა:** `RadioButton` ჯგუფი (Android, iOS, Web).
- **წესებზე დათანხმება:** `Switch` კომპონენტი.
- **ვალიდაცია:** ყველა ველის შემოწმება და იმეილის ფორმატის ვალიდაცია.
- **დიზაინი:** მუქი თემა (Dark Theme) ინდივიდუალური ფერებით.
